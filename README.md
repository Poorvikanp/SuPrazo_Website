# SuPrazo Technologies Website

Official website for **SuPrazo Technologies**, designed to showcase the company's ecosystem, products, initiatives, foundation, community programs, careers, and leadership.

The website is built as a modern responsive React application with a focus on clean UI, responsive layouts, animations, and user-friendly enquiry/application flows.

---

## 🚀🚀Features🚀🚀

- 🏢 Company information and ecosystem overview
- 🤖 Products and product enquiry sections
- 👨‍💼 Director's Office / Leadership profile
- 🌱 SuFalPra Foundation section
- 💡 Community and SuPrathon initiatives
- 💼 Careers and internship opportunities
- 📩 Email-based contact and enquiry forms
- 📱 Fully responsive design for desktop, tablet, and mobile
- 🎬 Video and image-based hero sections
- ✨ Scroll and entrance animations
- 🌐 Multi-language support(english and Hindi)
- 🧭 Responsive navigation with mobile menu
- 🔗 Social media and external links
- 🎨 Modern corporate UI with reusable components
